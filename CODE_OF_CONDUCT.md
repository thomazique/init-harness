# Código de conduta

Buscamos uma comunidade respeitosa, inclusiva e orientada a evidência. Não são
aceitos assédio, discriminação, ataques pessoais, exposição de dados privados ou
comportamento que prejudique deliberadamente colaboradores. Mantenedores podem
editar, remover ou rejeitar contribuições que violem estes princípios. Relatos
devem ser feitos de modo privado pelo perfil do mantenedor no GitHub.
